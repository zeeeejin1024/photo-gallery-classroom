# 摄影作品展示页

一个课堂使用的简单网页，用来展示作品并按风景、街景筛选。图片均为本项目原创 SVG 教学示意图，不是真实摄影照片。

## 怎样运行

取得完整项目后，用电脑上的浏览器打开 `index.html`。保持 `style.css`、`app.js`、`images/` 与首页的相对位置。这个项目不需要安装额外框架，也不需要账号、服务器或 API 密钥。

## 怎样使用

打开后显示 3 幅作品；点击“风景”显示 2 幅，点击“街景”显示 1 幅，点击“全部”恢复 3 幅。

## 文件用途

- `index.html`：页面结构和介绍文字。
- `style.css`：颜色、排版和不同屏幕下的布局。
- `app.js`：类别按钮与作品筛选。
- `images/`：三幅 SVG 教学示意图。
- `LICENSE`：本演示项目的 MIT 许可文本。

## 当前限制

只展示预设内容，没有上传照片、账号登录和后台管理功能。上传代码到 GitHub 不会自动完成网站部署。

## 课堂文字修改

初始介绍文字为“记录日常风景”。按课堂操作单修改为“记录日常风景与街角故事”，以观察保存、提交和推送的区别。
